# Vim

Vim 的核心是模式编辑，有3种主要模式：

1. **普通模式（Normal）** 默认模式，用于浏览和执行命令

2. **编辑模式（Insert）** 用于输入/编辑文字

3. **命令行模式（Command-line）** 用于保存、退出等操作

## 普通模式

### 进入编辑模式

| 按键  | 效果                     |
| ----- | ------------------------ |
| `i`   | 在光标前插入             |
| `a`   | 在光标后插入             |
| `o`   | 在下一行插入新行         |
| `I`   | 在行首插入               |
| `A`   | 在行尾插入               |
| `O`   | 在上一行插入新行         |
| `Esc` | 退出编辑模式回到普通模式 |

进入编辑模式后，底部会显示 `-- INSERT --`，这时可以正常打字。

### 移动光标

| 按键 | 效果                     |
| ---- | ------------------------ |
| `h`  | 光标左移                 |
| `j`  | 光标下移                 |
| `k`  | 光标上移                 |
| `l`  | 光标右移                 |
| ---  | 按单词跳转               |
| `w`  | 光标移动到下一个词开头   |
| `b`  | 光标移动到上一个词开头   |
| ---  | 行内跳转                 |
| `0`  | 光标移动到行首           |
| `^`  | 光标移动到第一个非空字符 |
| `$`  | 光标移动到行尾           |
| ---  | 文件跳转                 |
| `gg` | 光标跳转到文件开头       |
| `G`  | 光标跳转到文件结尾       |

### 文本操作

| 按键  | 效果           |
| ----- | -------------- |
| `x`   | 删除当前字符   |
| `dd`  | 删除行         |
| `dw`  | 删除到下一个词 |
| `d$`  | 删到行尾       |
| `yy`  | 复制当前行     |
| `yw`  | 复制一个词     |
| `p`   | 粘贴到光标后   |
| `P`   | 粘贴到光标前   |
| `u`   | 撤销           |
| `C-r` | 重做           |

### 可视模式

| 按键 | 效果       |
| ---- | ---------- |
| `v`  | 字符级选中 |
| `V`  | 整行选中   |
| `d`  | 选中后删除 |
| `y`  | 选中后复制 |

## 命令行模式

在普通模式下：

| 按键          | 效果                           |
| ------------- | ------------------------------ |
| `:q`          | 退出                           |
| `:q!`         | 强制退出，不保存修改           |
| `:wq` \| `ZZ` | 保存并退出                     |
| `:x`          | 保存并退出，仅当有修改时才写入 |

## 在 vscode 中使用 Vim

使用 [Vim](https://github.com/VSCodeVim/Vim) 插件

可以使用 Ctrl+Shift+P: `Vim: Toggle Vim Mode` 切换编辑模式，这样就可不用卸载插件
