# Vim

Vim 的核心是模式编辑，有3种主要模式：

1. **普通模式（Normal）** 默认模式，用于浏览和执行命令

2. **编辑模式（Insert）** 用于输入/编辑文字

3. **命令行模式（Command-line）** 用于保存、退出等操作

## Vim 操作

### 进入编辑模式

| 按键  | 效果                     |
| ----- | ------------------------ |
| `i`   | 在光标前插入             |
| `a`   | 在光标后插入             |
| `o`   | 在下一行插入新行         |
| `I`   | 在行首插入               |
| `A`   | 在行尾插入               |
| `O`   | 在上一行插入新行         |
| `Esc` | 退出编辑模式回到普通模式 |

进入编辑模式后，底部会显示 `-- INSERT --`，这时可以正常打字。

### 移动光标

| 按键 | 效果                     |
| ---- | ------------------------ |
| `h`  | 光标左移                 |
| `j`  | 光标下移                 |
| `k`  | 光标上移                 |
| `l`  | 光标右移                 |
| ---  | 按单词跳转               |
| `w`  | 光标移动到下一个词开头   |
| `b`  | 光标移动到上一个词开头   |
| ---  | 行内跳转                 |
| `0`  | 光标移动到行首           |
| `^`  | 光标移动到第一个非空字符 |
| `$`  | 光标移动到行尾           |
| ---  | 文件跳转                 |
| `gg` | 光标跳转到文件开头       |
| `G`  | 光标跳转到文件结尾       |

### 文本操作

| 按键  | 效果                   |
| ----- | ---------------------- |
| `x`   | 删除当前字符           |
| `s`   | 删除当前字符并进入插入 |
| `dw`  | 删除到下一个词         |
| `D`   | 删到行尾               |
| `C`   | 改到行尾               |
| `yw`  | 复制一个词             |
| `p`   | 粘贴到光标后           |
| `P`   | 粘贴到光标前           |
| `u`   | 撤销                   |
| `C-r` | 重做                   |
| ----- | 行操作                 |
| `dd`  | 删除当前行             |
| `yy`  | 复制当前行             |
| `cc`  | 改当前行               |
| `>>`  | 缩进                   |
| `<<`  | 反缩进                 |
| ----  | 复合操作               |
| `ciw` | 改当前词               |
| `diw` | 删当前词               |
| `viw` | 选当前词               |
| ----- | 处理引号/括号内容      |
| `ci"` | 改引号内内容           |
| `ci(` | 改括号内内容           |
| `di"` | 删引号内内容           |
| `di(` | 删括号内内容           |
| `vi"` | 选引号括内容           |
| `vi(` | 选括号内内容           |

> 数字+ 动作可以批执行，如 `5j` 向下移动5行，`3w` 前进三个单词，`3dd` 删除三行。  
> `.` 重复上一次修改

### 可视模式

| 按键        | 效果                         |
| ----------- | ---------------------------- |
| `v`         | 字符级选中                   |
| `V`         | 整行选中                     |
| `d`         | 选中后删除                   |
| `y`         | 选中后复制                   |
| ---         | ---                          |
| `C-v`       | 列选择                       |
| `gv`        | 重新选中上一次可视模式选区   |

### 文本搜索及替换

| 按键/命令           | 效果                     |
| ------------------- | ------------------------ |
| `/word`             | 向下搜索 `word`          |
| `?word`             | 向上搜索 `word`          |
| `n`                 | 跳到下一个匹配           |
| `N`                 | 跳到上一个匹配           |
| `*`                 | 向下搜索当前光标所在单词 |
| `#`                 | 向上搜索当前光标所在单词 |
| `:%s/old/new/g`     | 全文件搜素替换           |
| `:%s/old/new/gc`    | 全文件搜素替换并逐个确认 |
| `:10,20s/old/new/g` | 仅第10到20行搜素替换     |

> 替换命令中的分隔符不一定非要用 `/`，也可以用 `#`，例如 `:%s#path/a#path/b#g`，在处理路径时更清晰。

### 寄存器与剪贴板

普通编辑器通常只有一个复制粘贴缓冲区，Vim 有很多寄存器可以分别存不同内容。因此可以一边保留系统剪贴板内容，一边在 Vim 内部做多份复制、删除、粘贴，不互相覆盖。

命令一般是 `"x`  指定使用 `x` 号寄存器，然后指定操作，如 `"0p` 表示用 `0` 号寄存器里的内容来粘贴。

寄存器分类：
- 无名寄存器 "：默认复制/删除都会进这里
- 命名寄存器 a-z：手动存内容
- 追加寄存器 A-Z：向对应小写寄存器追加
- 数字寄存器 0：最近一次复制（yank）
- 数字寄存器 1-9：最近删除/修改历史
- 系统剪贴板寄存器 + 和 *

| 按键/命令     | 效果                             |
| ------------- | -------------------------------- |
| `"0p`         | 粘贴最近一次复制的内容           |
| `"ap`         | 粘贴 `a` 寄存器的内容            |
| `"ayw`        | 复制一个词到寄存器 `a`           |
| `"Ayw`        | 复制一个词追加当前行到寄存器 `a` |
| `"*p`         | 从系统选择区粘贴                 |
| `"+p`         | 从系统剪贴板粘贴                 |
| `"+yy`        | 复制当前行到系统剪贴板           |
| `:registers` | 查看所有寄存器内容               |

> p 的默认等价于用无名寄存器粘贴，也就是 ""p

### 功能操作

在普通模式下：

| 按键          | 效果                           |
| ------------- | ------------------------------ |
| `:q`          | 退出                           |
| `:q!`         | 强制退出，不保存修改           |
| `:wq` \| `ZZ` | 保存并退出                     |
| `:x`          | 保存并退出，仅当有修改时才写入 |

使用 [Vim](https://github.com/VSCodeVim/Vim) 插件

可以使用 Ctrl+Shift+P: `Vim: Toggle Vim Mode` 切换编辑模式，这样就可不用卸载插件
