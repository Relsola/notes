# Vim

Vim 的核心是模式编辑，有3种主要模式：

1. **普通模式（Normal）** 默认模式，用于浏览和执行命令

2. **编辑模式（Insert）** 用于输入/编辑文字

3. **命令行模式（Command-line）** 用于保存、退出等操作

## 普通模式

进入编辑模式

| 按键 | 效果             |
| ---- | ---------------- |
| `i`  | 在光标前插入     |
| `a`  | 在光标后插入     |
| `o`  | 在下一行插入新行 |
| `I`  | 在行首插入       |
| `A`  | 在行尾插入       |
| `O`  | 在上一行插入新行 |

进入编辑模式后，底部会显示 `-- INSERT --`，这时可以正常打字。

## 编辑模式

`Esc` 退出编辑模式回到普通模式

## 命令行模式

在普通模式下：

| 按键          | 效果                           |
| ------------- | ------------------------------ |
| `:q`          | 退出                           |
| `:q!`         | 强制退出，不保存修改           |
| `:wq` \| `ZZ` | 保存并退出                     |
| `:x`          | 保存并退出，仅当有修改时才写入 |
