# Emacs

`C Ctrl` | `M Alt`

C-g 取消操作

## 文件操作

C-x C-f 打开文件（没有则创建文件）
C-x C-s 保存文件

M-w 复制  C-y 粘贴  C-w 剪切  

C-/  C-_  C-x u 撤销(undo)
    - 打断撤销操作后，可以撤销`撤销`

C-x o 切换窗口分屏
C-x 0 关闭当前分屏
C-x 1 只留下当前分屏
C-x 2 上下分割
C-x 3 左右分割

## 光标移动

C-f 前进一步  C-b 后退一步  C-n 下一行  C-p 上一行
M-f 前进一个a单词  M-b 后退一个c单词

C-a 行首  C-e 行尾
M-a 句首  M-e 句尾

M-< h缓冲区开头  M-> 缓冲区结尾

C-v 向上翻页  M-v 向下翻页

C-s 正向搜索  M-s 逆向搜素

## Emacs-shell

M-p 上一条历史命令
M-n 下一条历史命令

## Emacs 宏

C-x ( 开始录制宏
C-x ) 结束录制宏

C-x e 执行一次刚才录制的宏，连续按 e 会重复执行上次宏操作

## Emacs 功能操作

C-s 正向增量搜素，重复使用 C-s 跳转到下一个匹配项
C-y 反向增量搜素，重复使用 C-y 跳转到下一个匹配项

C-u + 数字 | M + 数字  进行重复指令操作

M-% 搜素并替换  
    - y 替换本次出现
    - n 跳过本次出现
    - ! 替换所有剩下的匹配点
    - q 退出替换
    - . 只替换当前这个然后退出
    - ^ 跳回上一个匹配
    - e 修改这次替换的替换内容
    - C-r 进入递归编辑

C-M-% 正则替换

M-x compile 输入编译命令进行编译，在报错/警告位置按回车可跳转到源文件位置

M-x dired 浏览和管理当前目录

M-x grep | rgrep 搜索
