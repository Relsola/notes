# C/C++ 笔记

## 编译器常用编译参数

|    分类    | 功能               | GCC                          | MSVC                                                   | 补充说明                                        |
| :--------: | :----------------- | :--------------------------- | :----------------------------------------------------- | :---------------------------------------------- |
|  阶段控制  | 预处理             | `-E`                         | `/P`                                                   | 头文件展开和宏展开                              |
|            | 只编译不链接       | `-c`                         | `/c`                                                   |                                                 |
|            | 指定输出文件名     | `-o <file>`                  | 1. 目标文件 `/Fo:<file>`<br>2. 可执行文件 `/Fe:<file>` | MSVC 将 `.obj` 和 `.exe` 的输出路径参数显式区分 |
|  标准选择  | 指定 C++ 标准      | `-std=c++20 \| -std=gnu++23` | `/std:c++20 \| /std:c++preview`                        | gnu标准                                         |
|            | 指定 C 标准        | `-std=c17 \| -std=gnu23`     | `/std:c17`                                             |                                                 |
|  优化等级  | Debug 无优化       | `-O0`                        | `/Od`                                                  | 方便调试器定位和断点追踪                        |
|            | Release 性能优化   | `-O2 \| -O3`                 | `/O2 \| /Ox`                                           | `O2` 更均衡                                     |
|            | 体积优化           | `-Os`                        | `/O1 \| /Os`                                           | 嵌入式开发或严格控制二进制体积时使用            |
|  代码特性  | 禁用异常           | `-fno-exceptions`            | `/EHs-c-`                                              | 消除 `Exception` 处理的开销，减小体积并提升性能 |
|            | 禁用 RTTI          | `-fno-rtti`                  | `/GR-`                                                 | 禁用 `dynamic_cast` 与 `typeid`，精简虚表结构   |
|  警告控制  | 常规警告           | `-Wall`                      | `/W4`                                                  |                                                 |
|            | 严格警告           | `-Wextra`                    | `/W4`                                                  |                                                 |
|            | 将警告视作错误     | `-Werror`                    | `/WX`                                                  |                                                 |
| 头文件和宏 | 指定头文件搜索路径 | `-I<dir>`                    | `/I<dir>`                                              |                                                 |
|            | 定义预处理宏       | `-D<NAME>[=val]`             | `/D<NAME>[=val]`                                       |                                                 |
|  链接控制  | 指定链接器         | `-fuse-ld=<linker>`          |                                                        | 推荐 `Mold` 链接器                              |
